Schlüssel zum Speichern

So richtest du ihn ein
  1. Auf GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → nur dieses Repo.
  3. Permissions → Repository → Contents: Read and write. Sonst nichts.
  4. Ablauf z. B. 1 Jahr. Token kopieren und unten einfügen.

Der Schlüssel bleibt nur in diesem Browser gespeichert. Er darf nur die Wächter-Datei in diesem Repo ändern.
